Hotrod is an open-source Astro starter built for sites that are designed,
written, and maintained by coding agents.

This first post exists so the dev server boots into something real. Every
piece of content on this site — including marketing pages, author profiles,
and posts — lives as an MDX file under `src/content/`. The frontmatter is
validated by strict Zod schemas, so an agent (or a human editor) gets a
loud, clear error the moment something is wrong.

## What you get

Hotrod ships with Zod-typed blocks for building pages, Mux and Vercel Blob
ready for video and images, and a low-dependency setup, so there is very little
to install or maintain. There is no heavy CMS: everything that affects the
site lives in the repo, where your agent can read it.

## Who it is for

Non-technical founders with a coding agent and a marketing site to ship,
agencies and freelance developers, and engineers who are tired of starters
with a hundred dependencies they will never use.

## Getting started

The flow is simple: clone, repaint, write content, deploy. Fork the repo, point
your agent at it, and start shipping pages that compile.
